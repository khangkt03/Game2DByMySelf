# 📖 Giới thiệu

**Game2DByMySelf** là dự án cá nhân được thực hiện nhằm học tập và rèn luyện kỹ năng phát triển game 2D với Unity.

Trong quá trình thực hiện, mình đã xây dựng các chức năng cơ bản của một game platformer như điều khiển nhân vật, thu thập vật phẩm, tính điểm, nền tảng di chuyển và xử lý Game Over.

# 🎮 Điều khiển

| Phím | Chức năng |
|------|-----------|
| **A** | Di chuyển sang trái |
| **D** | Di chuyển sang phải |
| **Space** | Nhảy |

# 📸 Hình ảnh trong game

> Thay các ảnh dưới đây bằng ảnh chụp màn hình game của bạn.


### Cách chơi

1. Tải file **BuildGameFolder.rar**.
2. Giải nén file.
3. Mở thư mục vừa giải nén.
4. Chạy **Game2DByMySelf.exe**.
